# Developer EQ Sprint — AI Prompt Pack

These are standalone prompts you can paste into any AI (ChatGPT, Cursor, Claude.ai, Gemini, anything). One prompt per day of the sprint.

**If you use Claude Code:** install the skill instead. It's smarter — it tracks your progress, reads your git log, and runs the whole sprint without you copy-pasting. Install:

```bash
mkdir -p ~/.claude/skills && curl -o ~/.claude/skills/dev-eq.md https://raw.githubusercontent.com/ChaosKyle/developer-eq-sprint/main/dev-eq.md
```

Then run `/dev-eq` in Claude Code.

**If you don't use Claude Code:** these prompts are for you. Open one per day, paste into your AI of choice, do the exercise.

## How to use

1. Read `../workbook.md` for the full content (story points + acceptance criteria for each day)
2. Open today's prompt file (e.g. `01-skill-tree-audit.md`)
3. Copy the prompt block into your AI
4. Do the exercise interactively
5. Save your notes somewhere you'll find them (Notion, Obsidian, plain markdown, the PDF)
