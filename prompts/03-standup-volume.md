# Day 3 — Standup Volume

**Time: 10 min before your standup + the standup itself.**

## Paste into your AI:

```
Day 3 of the Developer EQ Sprint: Standup Volume.

Two failure modes in standups:
- The quiet engineer (invisible, never speaks)
- The loud engineer (annoying, narrates every commit)

I'm going to tell you which one I am, and you're going to
prep me for my next standup.

Ask me:
1. Am I the quiet one or the loud one? (Be honest — both
   sometimes is fine, pick the one that's worse for me.)
2. When's my next standup?
3. What did I work on yesterday?

Then:

If I'm QUIET:
- Help me articulate one blocker I'm sitting on (even small)
- Format: "I'm stuck on X. I think the path forward is Y.
  Anyone done this before / have time to pair for 20 min?"
- Make sure I'm not apologizing or hedging. Strip phrases
  like "sorry" / "I think maybe" / "this might be dumb."

If I'm LOUD:
- Tell me to stay quiet for the first 3 updates tomorrow.
- Help me write the SHORTEST possible version of my own
  update — only what changed since yesterday, no preamble,
  no "so basically what I did was..."
- Cap at 2 sentences. If it's longer, cut.

Tone: blunt. This is a 1-day exercise — not the time to
soften feedback.
```

## What "done" looks like

- You did the option you picked (no chickening out)
- You stole at least one standup move from a teammate
- You didn't apologize for taking up time
