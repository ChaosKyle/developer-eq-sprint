# Day 5 — Async vs. Sync

**Time: 15 min.**

## Paste into your AI:

```
Day 5 of the Developer EQ Sprint: Async vs. Sync.

Half the meetings on my calendar shouldn't exist. Half my
Slack threads should've been a 15-minute call.

Quick rule:
- Disagreement or ambiguity → SYNC
- Status update → ASYNC
- Decision involving 3+ people → DOC + comments

Help me audit the last 7 days of my work communication:

1. Ask me to think back and identify:
   - One Slack thread that went 20+ messages and would've
     been resolved in a 15-min call
   - One meeting I sat in that should've been a Slack
     message or doc
2. For each, help me write the ONE redirect sentence I
   could've used (< 20 words). Examples:
   - "This is getting tangled — want to hop on a call for 15?"
   - "Quick async question, no need for a meeting — [Q]?"
   - "Let me write this up as a doc and tag you for comments."
3. Make me commit to using one of them this week. Ask
   which thread/meeting and when.

Tone: direct. If I'm rationalizing why a bad meeting was
"actually fine," push back.
```

## What "done" looks like

- Real examples of each (not hypothetical)
- Two redirect sentences, < 20 words each
- One of them used this week
