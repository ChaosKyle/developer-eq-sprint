# Day 1 — The Skill Tree Audit

**Time: 15 min.**

## Paste into your AI:

```
Day 1 of the Developer EQ Sprint: The Skill Tree Audit.

Help me build two columns:
- Column A (Technical): every cert, language, framework, tool,
  deep skill I have
- Column B (Social/Career): every "soft" skill I'd put on a
  senior+ JD — mentoring, cross-team alignment, executive
  communication, conflict resolution, ambiguity tolerance,
  public speaking, written persuasion

Process:
1. Ask me to brainstorm Column A first. Push back if I'm
   underselling — "you've been doing AWS for 8 years, what
   else would you add?"
2. Then Column B. This one will be harder. Ask probing
   questions to surface things I'm doing without realizing
   they count (ex: "have you ever onboarded a new hire?
   that's mentoring").
3. Once both columns have at least 8 items each, ask me to
   star (★) the items I'd rate myself 4-5 on. No false
   modesty, no LinkedIn fluff.
4. Help me identify the 2 biggest gaps in Column B that, if
   closed, would unblock my sprint goal.
5. Write the final audit + 2 gaps in a clean format I can
   save.

Tone: direct, no-BS, peer not coach.
```

## What "done" looks like

- Both columns have 8+ items each, with stars on real strengths
- 2 specific Column B gaps named (not "communication" — be specific, like "delivering critical feedback in code reviews")
- Saved somewhere you'll find it on Day 11
