# Day 11 — Sprint Demo

**Time: 30 min. The most important page in the workbook.**

## Paste into your AI:

```
Day 11 of the Developer EQ Sprint: Sprint Demo.

I just finished 10 days. Today I'm presenting to myself.

Help me run the demo:

1. Re-run the Day 0 self-audit (1-5 scale on these 8):
   - Speaking up in standups when I have something to add
   - Pushing back on a decision I disagree with
   - Delivering critical feedback in a code review
   - Asking for what I want (raise, scope, role)
   - Following up with people I've met once
   - Staying calm when production is on fire
   - Driving my own 1:1 agenda
   - Saying "I don't know" without it costing me credibility

   Tally the new score, ask me my Day 0 score, calculate
   the delta. Don't sugar-coat — if I went down on
   something, ask why.

2. SPRINT VELOCITY: how many of the 10 exercises did I
   actually finish? (If <7, that's fine — the next sprint,
   I start with what didn't happen.)

3. WHAT SHIPPED: help me list the 3 things I actually DID
   during this sprint that I wouldn't have done otherwise.
   Specific actions, not generic learnings. ("Sent 3
   networking messages" not "got better at networking.")

4. NEXT SPRINT: help me pick ONE focus for the next 2 weeks:
   - Re-run any 3 standups that didn't land first time
   - Send the promotion brief and have the conversation
   - Apply Day 6 (calm voice) to a real incident
   - Commit to Follow-up Friday for a quarter
   - Start the book — go deeper on a chapter that hit
   - Other

5. Generate a SPRINT SUMMARY in markdown I can paste into
   a brag doc / promotion packet / LinkedIn post if I want.
   3-5 bullets, factual, no hype.

Tone: like a sprint retro with a respected peer. Honest.
No empty validation. Real wins get real recognition;
honest gaps get named.
```

## What "done" looks like

- New self-audit score + delta from Day 0
- Sprint velocity (X/10)
- 3 specific things you actually did
- One focus picked for the next 2 weeks
- Sprint summary saved (use it or don't — having it is the win)
